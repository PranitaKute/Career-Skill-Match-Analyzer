# Career Skill Match Analyzer

The **Career Skill Match Analyzer** is an AI-powered Streamlit application designed to analyze user-provided skills and compare them with industry-specific skill sets.  
It helps individuals identify their **career compatibility**, discover **skill gaps**, and gain **personalized insights** to improve their employability.

---

## Key Features

-  **Skill Matching Visualization** – Compare your skills with top in-demand career profiles through dynamic bar charts.  
-  **Career Compatibility Score** – Calculates how closely your skills align with each selected profession.  
-  **Insightful Analysis** – Highlights missing or weak skills to help you focus on relevant learning paths.  
-  **Interactive Streamlit Interface** – Simple, intuitive, and beginner-friendly web application.  
-  **Custom Skill Database** – Includes multiple careers such as Web Developer, Data Analyst, AI Engineer, Cybersecurity Expert, UI/UX Designer, Content Writer, and Project Manager.

---

##  Tech Stack

- **Frontend / Interface:** Streamlit  
- **Programming Language:** Python  
- **Libraries Used:** matplotlib, plotly, streamlit  
- **Data Processing:** Skill similarity and scoring using set-based matching  

---

##  How It Works

1. Upload your resume in pdf format or paste text in input box.  
2. The app compares your skills with predefined industry career skill sets.  
3. View a **bar chart** showing your compatibility percentage for each career.  
4. Identify missing skills to enhance your learning roadmap.
